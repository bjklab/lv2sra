# lv2sra

The *lv2sra* package is designed to generate `Microbe` (v1.0) and `Metagenome or environmental` (v1.0) BioSample submission descriptions to accompany sequence data submission to the NCBI SRA.  

It includes:  
+ functions to read common LIMS system reports
+ functions to output BioSample metadata tables, based on a directory containing sequence files and the LIMS system report matching the sequence filenames  

The *lv2sra* package has been used to support multiple submissions to the NCBI SRA.
